# LocalRise · 김해시보 태블릿/모니터 프론트엔드

2026 AIM Challenge / CO-SHOW 시연을 위한 React 기반 키오스크입니다.

- **태블릿**: 세로 화면에서 토더기 안내 → 7문항 → 김해시보 전자신문 → 기사 읽기 → 영상 생성 → 상영 안내 → 마무리
- **모니터**: 영상이 없을 때 김해시보 대기 지면, 상영 중에는 영상만 전체 화면에 출력
- **전자신문**: 이미지가 아닌 실제 HTML 기사 지면입니다. 터치/클릭으로 기사 열기, 세로 스크롤, 확대/축소, 두 손가락 확대 지원
- **캐릭터**: 로컬에서 별도로 제공하는 공식 토더기 이미지 6종만 사용합니다. 임의로 만든 포즈나 캐릭터는 사용하지 않습니다.
- **연동**: 같은 Wi-Fi의 태블릿과 모니터를 함께 동작시키는 SSE 상태 중계 서버 포함

## 시작하기

Node.js 20 이상이 필요합니다.

> **공개 저장소의 이미지 정책**: 원본 시안에 포함된 토더기 캐릭터, 김해 로고, 관광지 사진은 저작권·배포 허가를 확인할 수 없어 이 공개 저장소에 포함하지 않았습니다. 원본 자료를 사용할 권한이 있는 운영자는 배포가 허용된 이미지 파일을 `public/assets/`에 직접 배치해야 합니다. 파일 이름과 경로는 `src/data.js`에서 확인할 수 있습니다. 이미지를 넣기 전에는 일부 사진·캐릭터 영역이 비어 보입니다. `public/assets/`는 `.gitignore`에 등록되어 있어 커밋되지 않습니다.

```bash
npm install
npm run start
```

서버가 실행되면 다음 두 화면을 엽니다.

| 기기 | 주소 |
|---|---|
| 태블릿 | `http://서버PC_IP:4174/tablet` |
| 옆 모니터 | `http://서버PC_IP:4174/monitor` |

같은 Wi-Fi에 접속한 태블릿과 노트북을 사용해 주세요. 첫 번째 시연은 자동으로 **데모 모드**가 적용됩니다. 이 모드에서는 AI 영상 생성 대신 상태를 시뮬레이션하고, 모니터에는 해당 여행지 사진이 천천히 움직이는 대체 화면이 나옵니다. **실제 생성 영상이라고 표시하거나 주장하지 않습니다.**

빠른 리허설: `/tablet?demoSec=5`로 열면 생성 대기 시간이 5초입니다.

화면만 개발할 때: `npm run dev`. 다만 다른 기기와 동기화되는 시연에는 `npm run start`를 권장합니다.

기본 UI와 시연 서버 확인:

```bash
npm run test
npm run build
npm run test:server
```

## 실제 백엔드 연동

기존 Python API를 사용한다면 아래처럼 실행합니다.

```bash
API_UPSTREAM=http://127.0.0.1:5000 npm run start
```

그리고 태블릿 주소에 `?live=1`을 붙입니다.

- `GET /quiz` → `{questions:[...7개]}`
- `POST /recommend_quiz` → `{recommendations:[...5곳],persona_summary:'...'}`
- `POST /api/videos` → `{task_id:'...'}`
- `GET /api/video-status/{task_id}` → `{status:'running'|'succeeded'|'failed',progress:0..100,result:{video_url:'...'}}`

`video_url`은 **모니터 브라우저에서도 접근할 수 있는 주소**여야 실제 영상이 자동 재생됩니다. 브라우저 자동재생 제약을 고려해 영상은 처음에 음소거 상태로 시작합니다.

백엔드가 반환한 영상 URL이 없다면 모니터에는 사진 기반 대체 장면만 표시됩니다. AI 영상 생성과 데이터베이스는 이 프로젝트에 포함되지 않습니다.

## 부스 운영을 위한 조언

1. 태블릿을 세로로 고정합니다. 기준 시안은 **820 × 1180**입니다.
2. 모니터는 가로 16:9 전체 화면으로 띄웁니다. F11로 전체 화면 전환할 수 있습니다.
3. 두 기기가 반드시 같은 서버 주소로 접속해야 동기화됩니다.
4. 추천 신문은 동적으로 구성됩니다. 기사 제목이나 사진 영역을 터치하면 상세 기사가 열립니다.
5. 오작동 방지를 위해 질문/신문/기사 화면에서 5분 동안 입력이 없으면 처음으로 돌아갑니다. 영상 생성이나 재생 도중에는 이 타이머가 적용되지 않습니다.
6. 마무리 화면은 30초 후 자동으로 시작 화면으로 돌아갑니다.

## 프로젝트 구조

```text
src/
  App.jsx       화면·인터랙션·동작 상태
  api.js        추천/영상 API 및 실시간 화면 중계
  data.js       시연 데이터와 이미지 경로
  styles.css    태블릿 세로/모니터 가로 디자인
public/
  assets/brand/      로컬에서 별도로 추가하는 김해 로고 (Git 추적 제외)
  assets/characters/ 별도로 추가하는 공식 토더기 원본 6종 (Git 추적 제외)
  assets/places/     별도로 추가하는 여행 사진 (Git 추적 제외)
  fonts/             기존 시안의 글꼴
  mock/              기존 질문/추천 예시 JSON
server.mjs          같은 Wi-Fi 동기화 서버 + 선택적 Flask API 프록시
```

## 확인된 범위와 미완성 항목

- UI는 React/Vite 프로덕션 빌드로 검증할 수 있습니다.
- 실제 AI 영상 생성, 결과 영상 파일, QR 투표 시스템은 제공받지 않아 포함하지 않았습니다.
- 여러 부스에서 동시에 사용할 경우, 상태 중계 서버를 부스별로 별도 실행해야 합니다. 현재 중계 상태는 한 부스에 맞춘 프로세스 메모리 기반입니다.
- 공개 배포판에는 원본 캐릭터·로고·사진이 제외되어 있으며, 실제 부스 시연 전 별도 배치가 필요합니다.

원본 시안과 사용자 제공 캐릭터 자산의 저작권·배포 범위는 별도로 확인해 주세요.
